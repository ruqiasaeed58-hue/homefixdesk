# HomeFixDesk

**Live site: https://homefixdesk.online**

HomeFixDesk gives clear, practical answers to everyday home repair questions — what is wrong, why it happens, and how to fix it yourself, step by step. No filler, no ten-minute videos for a two-minute fix.

## What this repo is

This repository contains the full source of the HomeFixDesk website, built with [Hugo](https://gohugo.io/) (v0.167.0) and hosted on [Cloudflare Pages](https://pages.cloudflare.com/).

- `content/posts/` — the repair guides (question-format, long-form)
- `layouts/` — custom Hugo templates (cards, article pages, breadcrumbs, TOC)
- `static/` — CSS, images, `ads.txt`, `robots.txt`, favicon
